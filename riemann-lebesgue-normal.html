Riemann and Lebesgue Integration, and the Normal CDF

Exercise 1: numerical integration by partitioning the domain (Riemann) and the range (Lebesgue). Exercise 2: numerical computation of the standard normal CDF.

Exercise 1. Riemann and Lebesgue integration

The two approaches

Riemann. The interval [a, b] is split into n equal pieces. On each piece the function is replaced by its value at the midpoint, and the heights are added: Rn = Σ f(xi) · (b − a)/n. The midpoint is used because it also works for 1/√x, which is infinite at 0.

Lebesgue. The range of f is split into k levels y0 < y1 < … < yk. For each level we look at the preimage Ej = {x : yj ≤ f(x) < yj+1} and add Lk = Σ yj · μ(Ej), where μ is the length. This is the integral of a simple function that lies below f, so Lk is always a lower bound. The levels are equally spaced between the minimum and the maximum of f. For 1/√x, which has no maximum, the top level is cut at √k.

The new difficulty is the length μ(Ej). I used two ways to get it:

  • Exact preimage. We write G(y) = μ{f ≥ y}, which can be computed for these functions (for example G(y) = 1 − √y for x², and for sin(x)/x by bisection). Then μ(Ej) = G(yj) − G(yj+1). This needs k evaluations of G, but it requires knowing the shape of f.
  • Sampled preimage. We evaluate f on N grid points and count how many fall in each level. This only needs values of f, but the result depends on the grid.

Exercise 1. Pathological functions

  
Dirichlet function (1 on rationals, 0 on irrationals)

  
In every piece of a partition there are both rational and irrational numbers. A Riemann sum therefore depends on the points chosen: with rational points (such as i/n) every height is 1 and the sum is 1, with irrational points (such as i/n + 1/(n√2)) every height is 0 and the sum is 0. The upper Darboux sum is always 1 and the lower sum is always 0, so the function is not Riemann integrable. For the Lebesgue integral the rationals in [0, 1] form a countable set, which has length 0, so ∫ f = 1 · 0 + 0 · 1 = 0.

Thomae function (1/q at p/q, 0 at irrationals)

  
This function is continuous at every irrational number and discontinuous only at the rationals, which form a set of length 0. By Lebesgue's criterion it is Riemann integrable. Both integrals are 0: in the Lebesgue sense because the function is non-zero only on a countable set, and in the Riemann sense because for any ε only finitely many points have f ≥ ε. With rational points i/n (exact arithmetic) the Riemann sum is Σ gcd(i, n)/n². It tends to 0, but not smoothly: it is large when n has many divisors.

Exercise 1. Discussion

  
    
    
  • Same value. For all seven Riemann-integrable functions the two approaches converge to the same number, as the table shows. For 1/√x the Riemann integral is only an improper one (a limit), while the Lebesgue integral exists directly, and both give 2.
    • 
    
  • Accuracy and convergence. The midpoint Riemann sum converges with order 2 for smooth functions (error 8.2×10−9 for sin(x) at n = 10,000) and is exact for the piecewise linear and the step functions when the jump or corner is at a cell boundary. The Lebesgue lower sum has error at most h(b − a), where h is the height of a level, so it converges with order 1 for every bounded function, smooth or not (1.6×10−4 for sin(x) at k = 10,000). It never needs smoothness, but it is slower. For 1/√x both methods are slow, with order 1/2, because the function is unbounded.
    • 
    
  • Efficiency. To reach an error of about 10−6 on sin(x), Riemann needs about 1000 pieces, while the exact-preimage Lebesgue sum needs about 106 levels (22 ms against a fraction of a millisecond). In addition, the Lebesgue method needs the length of the preimages. The exact version needs the shape of f (or a root search for each level), and the sampled version, which only needs values of f, depends on the grid and cannot go below the grid error.
    • 
    
  • Where they behave differently. The Dirichlet function is not Riemann integrable but has Lebesgue integral 0. The Thomae function is integrable in both senses, but the Riemann sums converge irregularly. The step functions are easy for the Lebesgue approach, since only two values and two preimages are needed (the small error in the table comes only from the equally spaced levels, which do not contain the value 3 exactly). The strength of the Lebesgue integral is therefore theoretical (very general functions, limits), while for numerical work on ordinary functions the Riemann approach is simpler and much more efficient.

Exercise 2. Why the normal CDF is not elementary

  
The standard normal CDF is

  
Φ(x) = (1/√(2π)) ∫−∞x e−t²/2 dt = 1/2 + (1/√(2π)) ∫0x e−t²/2 dt.

  
The function e−t²/2 is continuous, so it has an antiderivative. The problem is that this antiderivative cannot be written with elementary functions (finite combinations of polynomials, exp, log, powers, trigonometric functions and their inverses). The result behind this is Liouville's theorem. In the form we need: let f and g be rational functions, with g not constant. Then ∫ f eg dx is elementary if and only if there is a rational function R with

  
R′(x) + R(x) g′(x) = f(x).

  
Here f = 1 and g = −x²/2, so the condition becomes R′ − xR = 1. No rational R can satisfy it:

  
    
    
  • If R is a polynomial of degree d ≥ 0, then xR has degree d + 1 and R′ has degree smaller than d, so R′ − xR has degree d + 1 ≥ 1 and cannot be the constant 1. R = 0 gives 0, not 1.
    • 
    
  • If R has a pole of order m ≥ 1 at a point a, then R′ has a pole of order m + 1 there, while xR has a pole of order at most m. So R′ − xR still has a pole at a and cannot be equal to 1.
    • 
  

  
Hence the integral of e−x²/2 is not elementary. This does not mean that Φ does not exist: it is a smooth, well-defined function, but it is a new function that must be defined by the integral itself.


  
The error function

  
The new function is given a name, the error function erf(x) = (2/√π) ∫0x e−t² dt. With the substitution t = s/√2 we get the exact representation

  
Φ(x) = 1/2 · (1 + erf(x/√2)) = 1/2 · erfc(−x/√2),   erfc = 1 − erf.

  
This is an exact analytic formula, but it only moves the problem: erf is defined by an integral, so to get a number we still need a numerical method. In practice the libraries combine several of them. For this reason I compared the following methods.






  
Exercise 2. Methods and implementation

  
    
    
  1. Trapezoidal rule and Simpson's rule for Φ(x) = 1/2 + ∫0x φ(t) dt with n panels, where φ is the normal density. Simple, but the number of panels must grow with |x|.
    2. 
    
  2. Alternating power series. Expanding the exponential gives Φ(x) = 1/2 + (1/√(2π)) Σk (−1)k x2k+1 / (2k k! (2k+1)). It converges for every x, but the terms have alternating signs and become very large before they shrink, so for large |x| almost all digits are lost by cancellation.
    3. 
    
  3. Series with positive terms. Let h(x) = ex²/2 ∫0x e−t²/2 dt. Then h′ = xh + 1 (note that this is the same equation as R′ − xR = 1 above, now with the solution h). Writing h = Σ ak x2k+1 gives a0 = 1 and ak = ak−1/(2k + 1), so
      
    Φ(x) = 1/2 + φ(x) (x + x³/3 + x5/(3·5) + x7/(3·5·7) + …).
    
      All terms are positive for x > 0, so there is no cancellation. For x < 0 and large |x| the result is still bad, because Φ is tiny and is computed as 1/2 minus a number close to 1/2.
    4. 
    
  4. Continued fraction for the tails. For x > 0 the upper tail is Q(x) = 1 − Φ(x) = φ(x) / (x + 1/(x + 2/(x + 3/(x + …)))), which converges quickly for x ≥ 2.5, with no subtraction. By symmetry Φ(−x) = Q(x).
    5. 
    
  5. Hybrid method (the one I propose). The positive series for |x| ≤ 2.5 and the continued fraction for |x| > 2.5. It uses only multiplications and divisions.
    6. 
    
  6. Through erf. Φ(x) = erfc(−x/√2)/2 with the C library function, as a comparison.
    7. 
  


def pdf(t):  return math.exp(-t * t / 2) / math.sqrt(2 * math.pi)

def simpson(x, n=100):                        # n even
    h = x / n
    s = pdf(0) + pdf(x) + sum((4 if i % 2 else 2) * pdf(i * h) for i in range(1, n))
    return 0.5 + s * h / 3

def series_pos(x):                            # 1/2 + pdf(x) * (x + x^3/3 + x^5/15 + ...)
    s = term = x; k = 0
    while abs(term) > 1e-17 * abs(s):
        k += 1; term *= x * x / (2 * k + 1); s += term
    return 0.5 + pdf(x) * s

def tail_cf(x, depth=60):                     # Q(x) for x > 0
    f = x
    for k in range(depth, 0, -1): f = x + k / f
    return pdf(x) / f

def phi(x):                                   # hybrid
    if abs(x) <= 2.5: return series_pos(x)
    q = tail_cf(abs(x), 60 if abs(x) > 4 else 120)
    return 1 - q if x > 0 else q

Exercise 2. Conclusions

  
    
    
  • Numerical integration. The trapezoidal error is divided by 4 when n is doubled (order 2) and the Simpson error by 16 (order 4). At x = 1 with n = 256 the errors are 3.1×10−7 and 6.3×10−13. Simpson is much better, but both need more panels as |x| grows, and in the tails the relative error is large, because Φ(x) is computed as 1/2 minus an integral. At x = −8 the relative error is still 1.8% for Simpson with n = 100.
    • 
    
  • Series. The alternating series is accurate for x up to 3 (relative error about 10−16, and 10−13 at x = −3) but needs more terms as |x| grows (11 terms for 10−12 at x = 1, 27 at x = 3, 51 at x = 5). At x = 8 it never gets better than about 4×10−6 because of cancellation, and at x = −8 it is completely wrong (relative error 1021). The positive series fixes the cancellation but not the problem for negative x.
    • 
    
  • Hybrid method. It gives about 14 correct digits everywhere in [−8, 8] (worst relative error 2.4×10−14, near the switch at |x| = 2.5), costs about 2.5 μs per value in Python, and is roughly 10 times faster than Simpson and 50 or more times faster than the trapezoidal rule, while being far more accurate.
    • 
    
  • erf from the library. It is the fastest (about 0.13 μs, written in C) and accurate to about 10−14 relative error. This is the method to use in practice, but it is itself built from series, continued fractions and rational approximations like the ones above.
    • 
    
  • Why numerical methods are still needed. Liouville's theorem shows that no closed formula in elementary functions exists. The error function gives an exact definition of Φ, but a value such as Φ(1.96) = 0.97500210485… can only be obtained by a numerical algorithm, and the choice of the algorithm (series near 0, continued fraction in the tails, relative error of the tails) decides how many digits are correct.
